# Samiksha Zelkar: Portfolio

Single-file portfolio site (`index.html`), no build step.

## Deploy on GitHub Pages
1. Create a public repo named `samikskhazelkar.github.io` (or any name, e.g. `portfolio`).
2. Upload `index.html` and `README.md` to the `main` branch.
3. Repo Settings > Pages > Build and deployment > Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`.
4. Wait a minute. Site goes live at `https://samikskhazelkar.github.io/` (or `/portfolio/` for a differently named repo).
